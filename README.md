# Tic-Tac-Toe

Simple command-line tic-tac-toe for two players.

## Play online (no Python required)

### Option A: Open in a browser

1. Open `index.html` in your browser (double-click it or use **File → Open**).
2. Play immediately.

### Option B: GitHub Pages (shareable link)

1. Push this repository to GitHub.
2. In **Settings → Pages**, set the source to the default branch and `/ (root)`.
3. Visit the published URL and play in the browser.

## Run the CLI version (Python)

```bash
python main.py
```

## How to play

- The board uses 3x3 squares.
- Players take turns placing `X` and `O`.
- First to line up three wins, otherwise it's a draw.
